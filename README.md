# Pepe - The Jump & Run Saga

Help the main character, Pepe, win the battle against the formidable chicken army and save the world from the menacing **GIANT CHICKEN!** This project is a classic Jump & Run game, built as a hands-on exercise in **Object-Oriented Programming (OOP)** as part of the Developer Akademie curriculum.

---

## About The Game

Dive into an epic adventure where Pepe faces off against an endless onslaught of feathered foes. Smaller chickens can be defeated with skillful jumps or by unleashing a **well-aimed bottle of fiery salsa** – a precious resource you'll collect throughout your journey. Be strategic with your salsa, as you'll need it for the ultimate showdown! Every encounter with a chicken costs you valuable lives, so stay agile and precise.

The grand finale awaits: The Boss Chicken! Your mission is to make it so hot it turns into a perfectly roasted one. Are you ready to lead Pepe to victory?

---

## Gameplay Highlights

* **Classic Jump & Run Mechanics:** Navigate through dynamic levels, jumping over obstacles and enemies.
* **Combat System:** Defeat smaller chickens by stomping on them or with projectile attacks (salsa bottles).
* **Collectibles:** Gather salsa bottles and coins throughout the game to boost your arsenal and score.
* **Boss Battle:** A challenging final encounter against the GIANT CHICKEN, requiring strategic use of collected salsa.
* **Life System:** Manage your precious lives carefully, as each chicken encounter costs you.

---

## Technologies Used

This game is primarily built with web technologies, emphasizing client-side logic and rendering:

* **JavaScript (78.1%)**: The core game logic, OOP implementation, collision detection, character movement, enemy AI, and rendering are all powered by JavaScript.
* **CSS (20.4%)**: Handles the styling of game elements, backgrounds, and the overall visual presentation.
* **HTML (1.5%)**: Provides the basic structure of the game canvas and any overlay UI elements.

---

## Development & Learning

This project was an experience in understanding and applying **Object-Oriented Programming (OOP)** principles in a real-world game development context. It covers concepts such as class structures, inheritance, polymorphism, and game loop management.
